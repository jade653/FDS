# 과제 배경과 범위

## 과제

**이상거래 탐지 솔루션 개발: 이상 탐지 시 자동 대응(지갑 동결, 블랙리스트 등록) 기능 탑재**

정식으로 운영할 서비스가 아니라 시험용 개발이다.

## 배경

- 회사는 자체 EVM 호환 체인을 운영하고 있다. 하지만 이 체인에서는 거래가 거의 일어나지 않는다.
- 자체 체인의 네이티브 토큰에 지갑 동결이나 블랙리스트를 구현하는 것은 시험용 개발로 적절하지 않다고 판단했다.
- 그래서 먼저 이더리움 Sepolia 테스트넷에 ERC-20 토큰을 발행하고, 그 토큰에 자동 대응을 구현하기로 했다.
- 방향을 정하는 과정에서 두 가지가 고려됐다.
  - 대표의 관심: 증권형·스테이블형 코인
  - 최근 Binance 해킹 사고로 대규모 스테이블코인이 탈취된 사건
- 그 결과 주제를 **"스테이블형 코인의 이상거래 자동 대응"**으로 정했다.
- 레퍼런스는 **USDT와 USDC**다.

## 범위

**포함**
- Sepolia 테스트넷에 스테이블형 ERC-20 토큰 발행
- 해당 토큰의 이상거래 탐지
- 탐지 시 자동 대응: 지갑 동결, 블랙리스트 등록
- 이후 자체 EVM 체인에 테스트 발행

**제외**
- 자체 체인 네이티브 토큰에 대한 동결·블랙리스트
- 정식 서비스 운영

## 알려진 조건

- 자체 체인에는 거래가 거의 없다. Sepolia에서도 이 토큰의 실제 이용자 거래는 없다.
- 자체 EVM 체인에 대해 알려진 사양:
  - EVM은 Paris 이하다. PUSH0을 지원하지 않으며, MCOPY·TSTORE도 지원하지 않는다.
  - 과거에 solc 0.8.19로 컴파일한 컨트랙트를 배포한 적이 있다. 0.8.20 이상은 시도한 적이 없다.
  - 이전에 배포 시 `invalid opcode` 오류가 났고, solc를 0.8.19로 낮춰 컴파일해 해결했다.
- 자체 EVM 체인에 대해 아직 정해지지 않았거나 확인되지 않은 것: chainId, RPC 주소, 블록 생성 주기, 익스플로러 유무, WebSocket pending 트랜잭션 구독 지원, Safe(멀티시그) 컨트랙트 배포 여부, EIP-7702 지원, 프라이빗 트랜잭션 제출 경로.
